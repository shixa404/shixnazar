# ⚽ JamoaX — Futbol uchun adolatli jamoalar tuzish vositasi

**JamoaX** — futbol va turli sport o'yinlari uchun o'yinchilarni adolatli, tasodifiy va rollar (darvozabon, himoyachi, yarim himoyachi, hujumchi) bo'yicha teng guruhlarga bo'lib beruvchi zamonaviy web-ilova.

Loyiha ichiga o'yin taktikasi va maslahatlar beruvchi **AI Murabbiy** ham integratsiya qilingan.

## 👤 Muallif

* **Muallif:** Shixnazar Obodov

* **Loyiha nomi:** JamoaX

## 🌟 Asosiy imkoniyatlari

* 👥 **2 dan 24 tagacha o'yinchi:** O'yinchilarni osongina qo'shish va olib tashlash.

* ⚽ **Rollar bo'yicha balans:** Har bir o'yinchiga rol berish (Darvozabon, Himoyachi, Yarim himoyachi, Hujumchi) va guruhlarni ushbu rollar bo'yicha ham teng bo'lish.

* 🎲 **Fisher–Yates algoritmi:** Xolis va 100% tasodifiy taqsimot.

* 💾 **Lokal saqlash (LocalStorage):** Kiritilgan o'yinchilar va tuzilgan jamoalar brauzer xotirasida saqlanadi.

* 🤖 **AI Murabbiy:** Tuzilgan jamoalarga qarab taktika, o'yin g'oyalari va maslahatlar beruvchi sun'iy intellekt (Groq / Anthropic API / Gemini).

* 🌙 **Tungi va Kunduzgi rejim (Dark/Light Mode):** Foydalanuvchiga qulay dizayn.

* 📱 **Responsive & Mobile Friendly:** Mobil qurilmalarda bir qo'lda ishlatish uchun moslashtirilgan.

## 🛠 Ishlatilgan texnologiyalar

* **HTML5** — Strukturaviy va semantik belgilash

* **CSS3** — Custom Properties (Variables), Flexbox, Grid, Animations & Dark Mode support

* **JavaScript (ES6+)** — Fisher–Yates shuffle algoritmi, DOM manipulyatsiyasi va LocalStorage

* **REST APIs** — AI Murabbiy ulanishi uchun Groq API / Anthropic / Gemini integration

## 🚀 Ishga tushirish (Usage)

Ushbu loyihani ishga tushirish uchun hech qanday qo'shimcha paketlar (Node.js, npm va h.k.) o'rnatish shart emas.

1. Kodni yuklab oling yoki `index.html` faylini yarating.

2. Faylni xohlagan brauzeringizda oching (masalan, Chrome, Firefox, Safari).
